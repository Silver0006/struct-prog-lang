# struct-prog-lang
2026 Spring Structure of Programming Languages

# Instructions
1. Compile the C++ library using cmake
    1. Enter cpp directory
    2. cmake -B build
    3. cmake --build build --parallel
    4. find "trivialCPP.cpython-{python version}-{cpu architecture}-{operating system}.so" in build directory
2. Transfer library to trivial directory
3. Run trivial
